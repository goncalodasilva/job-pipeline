## Manual checklist — user confirmation required

Use fictional jobs and contacts in a temporary data folder (`JOBPIPELINE_ALLOW_FAKE_PROVIDERS=1 uv run jobpipeline --data-dir
/tmp/jobpipeline-m5-review --no-browser`). Use the practice provider if desired. There is no
live-provider requirement for M5 and no credential needs to be shared with an agent.

- [ ] Open Board, table, an application drawer and Today at desktop and phone width in light
  and dark themes. Check labels, readable counts, empty states, focus and absence of sideways
  scrolling. On a phone use Menu to open navigation.
- [ ] Apply to a fictional job; move it with the keyboard menu and, on desktop, drag it. Check
  history, Closed expansion, and the optional Interviewing date / Rejected feedback dialogs.
  Skip or Escape should retain the status change. Check the pointer menu in Safari if used.
- [ ] Add/edit a note, event and company contact; link/unlink the contact and log an
  interaction. Confirm the company history and the informational recent-application note.
  Review the first drawer and Today checkpoints. Migration 0005's earlier checkpoint is
  recorded in PROGRESS; continuing the run did not mark native-calendar checks complete.
- [ ] Create a timed interview in a named IANA zone, note its date, start/end time and zone,
  and download the calendar file. **Import that actual .ics into your own calendar app and
  confirm its date, start/end time and time zone** (account for the calendar's display zone).
  Also check an all-day deadline; if you use dates near a clock change, check those too.
- [ ] Make a past follow-up and see it on Today and in Notifications. Try Done, Snooze and
  Dismiss, unseen counts and the card's Follow-up due marker. Close/reopen the app: overdue
  reminders appear when read, with no email, push notification or work while closed.
- [ ] Confirm acceptance of M5 after these checks, or report the failing step and observed
  behavior. Until then M5 stays planned and M6 does not start.
