  - The guide's existing `#form-error` has both `role="alert"` and focus, so it may be read twice.
  - A tier save swaps the whole Providers section, clearing a key typed but not saved; the model options don't mark the provider default.
  - The full keyboard walk runs at desktop only (phones are covered by tap, axe and layout checks).
  - A missing network shows as a wait of up to 60 s before "No connection".
