The form (one file, or pasted text) posts as multipart and swaps this whole section, as do a kept upload's Start and the budget dialog's Continue, which this section holds when the budget gate has a question: the dialog alone would replace the form. The notice says where the CV's text goes, and the button is described by it; with the practice provider saved, a second notice says that it reads no CV and makes fictional example drafts. After a start the status line takes focus (it is outside the list, which refetches itself while the task runs) and the same words go to the live region. A refused upload answers 400 or 413 with the reason: app.js lets a region marked data-shows-refusals show it. The fields are emptied by every answer: the upload is kept and listed below, so nothing is sent twice. When an import fails, the task indicator's sentence sends the user to the Tasks panel; on this page the reason is in the upload's own row, so app.js says the other sentence instead (data-announce-instead-of, data-announce-instead: both fixed, from the server). #}
