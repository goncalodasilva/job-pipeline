{# Settings > Prompts > one task: the protected editor (M9.3 part B; ADR-055; spec 2.9 rule 13, 3.3 and 3.6). It replaces #prompt-editor (outerHTML), whether it arrives by the load of the task page (GET .../editor) or as the answer to a form, and it never reloads itself. The prompt text is shipped or user-written template text: it is always escaped, and the default is shown as text, never rendered. Exactly one element of an answer takes focus (a plain load takes none): the status line after a save or reset, the first text area after a refusal or the reload prompt after a stale version (then there is no form, so a second Save can't overwrite what changed elsewhere). Needs `editor` (app/api/prompt_forms.py). #}
